Simplifying: factor numerator and denominator, cancel common factors.

Adding fractions:  \frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}

Complex fractions: multiply numerator and denominator by LCD.

Rational equation: multiply both sides by LCD, check extraneous solutions.

Example:  \frac{5}{x} - \frac{3}{x+4} = 2
5(x+4) - 3x = 2x(x+4)
5x+20-3x = 2x^2+8x
2x+20 = 2x^2+8x
x^2+3x-10 = 0
(x+5)(x-2) = 0 \rightarrow x=-5  or  x=2

Rational functions and asymptotes:
Vertical asymptote: where denominator = 0
Horizontal asymptote: compare degrees of numerator and denominator
\begin{array}{ll}
\deg(num) < \deg(den) & y = 0 \\
\deg(num) = \deg(den) & y = \frac{leading coeff num}{leading coeff den} \\
\deg(num) > \deg(den) & no horizontal asymptote
\end{array}

x-intercept: set numerator = 0  (where denominator \ne 0).
