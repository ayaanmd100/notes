=====================================
1. COMPLEX NUMBERS
=====================================

Imaginary unit and cycle of powers:
$$i = \sqrt{-1}$$
$$i^2 = -1$$
$$i^3 = -i$$
$$i^4 = 1$$

Reducing large powers (divide exponent by 4, use remainder r):
$$i^n = i^r \quad \text{where} \quad r = n \;\text{mod}\; 4$$

Example reduction:
$$i^{2026} \to 2026 = 4 \times 506 + 2 \to i^{2026} = i^2 = -1$$

Sum of consecutive powers (any 4 consecutive powers sum to 0):
$$i^k + i^{k+1} + i^{k+2} + i^{k+3} = 0$$

Arithmetic operations:
$$(a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i$$
$$(a + bi)(c + di) = (ac - bd) + (ad + bc)i$$

Modulus (Absolute Value):
$$\left| a + bi \right| = \sqrt{a^2 + b^2}$$
