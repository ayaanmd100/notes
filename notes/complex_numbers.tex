i = \sqrt{-1}, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1

Powers of  i  cycle with period 4.
To find  i^n: compute  r = n  mod  4, then:

\begin{array}{|c|c|}
\
r & i^n \\\
0 & 1 \\\
1 & i \\\
2 & -1 \\\
3 & -i \\\
\end{array}

Example:  i^{2026} = i^{4 \cdot 506 + 2} = i^2 = -1

Sum of any 4 consecutive powers of  i  equals zero:
i^k + i^{k+1} + i^{k+2} + i^{k+3} = 0

Example (2013 \#15): 
i^2 + i^3 + i^4 + i^5 + i^6 + i^7 + i^8 = 0 + 0 + i^8 = i^0 = 1

Group from  i^2:  (i^2+i^3+i^4+i^5)+(i^6+i^7+i^8)
but handle remainder carefully.

Arithmetic: 
(a + bi) + (c + di) = (a+c) + (b+d)i

(a + bi)(c + di) = (ac - bd) + (ad + bc)i

\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{c^2 + d^2}
= \frac{ac + bd}{c^2 + d^2} + \frac{bc - ad}{c^2 + d^2}\,i

Modulus:  |a + bi| = \sqrt{a^2 + b^2}

Conjugate:  \overline{a + bi} = a - bi

Conjugate Root Theorem:
If  a + bi  is a zero of a polynomial with real coefficients,
then  a - bi  is also a zero.

Polynomial with zeros  2,\, 3i,\, -3i:
P(x) = (x - 2)(x - 3i)(x + 3i) = (x-2)(x^2 + 9)
= x^3 - 2x^2 + 9x - 18
so  a = -2,\; b = 9,\; c = -18,\quad a+b+c = -11
