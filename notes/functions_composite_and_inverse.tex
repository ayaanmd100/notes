1. Composite function: $(f \circ g)(x) = f(g(x))$

2. Inverse function — swap x and y, then solve for y.

$$ f(x) = \frac{3x+2}{2x-3} \rightarrow f^{-1}(x) = \frac{3x+2}{2x-3} $$

(This function is its own inverse.)

3. Shortcut: $f^{-1}(v) = w$ means $f(w) = v$. Solve directly.

4. Function from set of ordered pairs: for $f = \{(3,5),(5,7),(2,3)\}$, domain = {2,3,5}, sum of domain = 10.

5. Function operations

$$ (f+g)(x) = f(x)+g(x) $$

$$ (fg)(x) = f(x) \cdot g(x) $$

$$ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} $$
