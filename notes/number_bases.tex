1. Converting base b to base 10

$$ (d_n \cdot\cdot\cdot d_1 d_0)_b = d_n b^n + \cdot\cdot\cdot + d_1 b + d_0 $$

2. Example

$$ (264)_b = 2b^2+6b+4, \quad (1030)_c = c^3+3c $$

3. Two-base problem: set equal, note digit constraints (digit d requires base > d).

4. Same-digit four-digit number

$$ (mmmm)_{m+1} = m\left[(m+1)^3+(m+1)^2+(m+1)+1\right] $$

5. Converting decimal to base b: repeatedly divide by b, record remainders (bottom to top).
