\text{Evaluate from the innermost level outward.}

\text{For repeating continued fractions, set the repeating part equal to } x\text{.}

\text{Example: } x = 2 + \frac{1}{3 + \frac{1}{x}}
3 + \frac{1}{x} = \frac{3x+1}{x}
x = 2 + \frac{x}{3x+1} = \frac{7x+2}{3x+1}
3x^2+x = 7x+2 \rightarrow 3x^2-6x-2=0
x = \frac{6 \pm \sqrt{36+24}}{6} = 1 \pm \frac{\sqrt{15}}{3}
\text{Take positive root: } x = \frac{3+\sqrt{15}}{3}

\text{Then for } 1 + \frac{1}{x}\text{:}
1 + \frac{1}{x} = 1 + \frac{3}{3+\sqrt{15}} = 1 + \frac{3(3-\sqrt{15})}{9-15}
= 1 - \frac{3-\sqrt{15}}{2} = \frac{-1+\sqrt{15}}{2}
