Basic step:
x^2 + bx = \left(x + \frac{b}{2}\right)^2 - \frac{b^2}{4}

General quadratic:
ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}

Vertex form:
f(x) = a(x - h)^2 + k
\quad h = -\frac{b}{2a}, \quad k = c - \frac{b^2}{4a}

Example:  2x^2 - 8x + 3
= 2(x^2 - 4x) + 3
= 2\!\left[(x-2)^2 - 4\right] + 3
= 2(x-2)^2 - 5
\quad \rightarrow vertex  (2, -5)

Completing the square for circles/ellipses/hyperbolas:
x^2 + 2x + y^2 - 12y + 3 = 0
(x^2 + 2x + 1) + (y^2 - 12y + 36) = -3 + 1 + 36
(x+1)^2 + (y-6)^2 = 34
\rightarrow center  (-1, 6), radius  \sqrt{34}

General completing-the-square for conic:
Ax^2 + Bx + Cy^2 + Dy + E = 0
A\!\left(x + \frac{B}{2A}\right)^2 + C\!\left(y + \frac{D}{2C}\right)^2 = \frac{B^2}{4A} + \frac{D^2}{4C} - E

Min/max using vertex form:
If  a > 0: minimum value = k
If  a < 0: maximum value = k

Example:  f(x) = -2x^2 + 5x + 3
h = -\frac{5}{2(-2)} = \frac{5}{4}
k = 3 - \frac{25}{4(-2)} = 3 + \frac{25}{8} = \frac{49}{8}

Finding  k  such that min of  x^2 - 2kx - k = -6:
vertex  y = -k - k^2 = -6
k^2 + k - 6 = 0
(k+3)(k-2) = 0
\rightarrow k = -3  or  k = 2, sum = -1
