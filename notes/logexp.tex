=====================================
2. LOGARITHMS AND EXPONENTS
=====================================

Definition (where b > 0, b \ne 1, x > 0):
$$\log_b(x) = y \quad \text{iff} \quad b^y = x$$

Core identities:
$$\log_b(1) = 0$$
$$\log_b(b) = 1$$
$$b^{\log_b(x)} = x$$

Properties of Logarithms:
$$\log_b(MN) = \log_b(M) + \log_b(N)$$
$$\log_b\left(\frac{M}{N}\right) = \log_b(M) - \log_b(N)$$
$$\log_b(M^p) = p \log_b(M)$$

Change of base formula:
$$\log_b(x) = \frac{\log_c(x)}{\log_c(b)} = \frac{\ln(x)}{\ln(b)}$$

Chain rule of logs:
$$\log_a(b) \cdot \log_b(c) = \log_a(c)$$

Natural log identities:
$$\ln(\exp(x)) = x$$
$$\exp(\ln(x)) = x$$

Solving exponential equations:
Equal bases: set exponents equal.
Otherwise: take log of both sides and apply the power rule.
