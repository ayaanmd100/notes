1. Congruence: a is congruent to b mod m when m divides (a-b).

2. Units digit cycles:
- base 2: 2,4,8,6 (period 4)
- base 3: 3,9,7,1 (period 4)
- base 7: 7,9,3,1 (period 4)
- base 9: 9,1 (period 2)
- base 5: 5 (period 1)
- base 4: 4,6 (period 2)

3. Example: units digit of $3^{33} + 5^{55} + 7^{77} + 9^{99}$

33 mod 4 = 1, so $3^{33}$ ends in 3.
77 mod 4 = 1, so $7^{77}$ ends in 7.
99 mod 2 = 1, so $9^{99}$ ends in 9.

$$ 3+5+7+9=24 \rightarrow units \; digit = 4 $$

4. Remainder of $mn+m+n$ when $n \equiv 1$ (mod 8) and $m \equiv 4$ (mod 8)

$$ mn+m+n \equiv 4+4+1=9 \equiv 1 \quad (mod \; 8) $$
