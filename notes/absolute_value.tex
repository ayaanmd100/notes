|x| = \begin{array}{ll} x & if  x \ge 0 \\ -x & if  x < 0 \end{array}

Equation  |f(x)| = k:  f(x) = k  or  f(x) = -k

Inequality  |f(x)| < k:  -k < f(x) < k \quad (k > 0)

Inequality  |f(x)| > k:  f(x) > k  or  f(x) < -k
