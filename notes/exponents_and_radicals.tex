a^m \cdot a^n = a^{m+n}

\frac{a^m}{a^n} = a^{m-n}

(a^m)^n = a^{mn}

(ab)^n = a^n b^n

a^0 = 1 \quad (a \ne 0)

a^{-n} = \frac{1}{a^n}

a^{m/n} = \sqrt[n]{a^m} = \left(\sqrt[n]{a}\right)^m

Simplifying radicals:
\sqrt{a \cdot b} = \sqrt{a} \cdot \sqrt{b}

\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}

Rationalizing:  \frac{a}{\sqrt{b}} = \frac{a\sqrt{b}}{b}

\frac{a}{\sqrt{b}+\sqrt{c}} = \frac{a(\sqrt{b}-\sqrt{c})}{b-c}

Example (2026 \#12):  k = \sqrt{340} - \sqrt[3]{625}
\sqrt{340} = 2\sqrt{85}, \quad \sqrt[3]{625} = 5\sqrt[3]{5}
k = 2\sqrt{85} - 5\sqrt[3]{5}

Solving radical equations: isolate radical, square both sides,
check for extraneous solutions.
-2 = -x + \sqrt{-5x+46}
\sqrt{-5x+46} = x - 2
-5x + 46 = x^2 - 4x + 4
x^2 + x - 42 = 0
(x+7)(x-6) = 0 \rightarrow x = -7  (extraneous),\; x = 6

Simplify mixed radicals (2024 \#3):  (\sqrt[3]{9})(\sqrt[4]{16})(\sqrt[6]{36})
